Search setup

Searching YouTube needs a free API key. Links work without one.

  1. Open console.cloud.google.com and create a project.
  2. Enable "YouTube Data API v3".
  3. Credentials, then Create credentials, then API key.
  4. Restrict the key to this site's address, then paste it below.

The key is saved in this browser only. The free quota allows roughly 100 searches a day.
